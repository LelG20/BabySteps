# GradeCalculator
A Simple Assignment of a Python-based program that adds up and finds the average of grades input by an individual.

The assignment is split into 7 parts:

1. VARIABLES & DATA TYPES
2. OPERATORS
3. DECISION STRUCTURES
4. LOOPS
5. FUNCTIONS
6. MODULES
7. GradeCalculator

Each part preceding part 7 is meant to teach you the basics of that individual concept and part 7 teaches you how to combine them into a single program.

I did each part of the assignment in it's own text file that matches the respective titles with exception to step 6, which meets it's absolution in grading_utils.py and gradecalc.py. I denoted the steps mentioned in the original assignment through comments to make it easy to follow along. 

I have also included an extra file titled gradecalc_improv that adds 2 improvements to the original: 

1. It makes sure the input grades are between 0 and 100
2. It lists the subjects down along with the grades
